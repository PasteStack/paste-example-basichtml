This is heroscroll

paste.ui.heroscroll moves the picture behind this section slower than the page, and fades the words as the section leaves the top of the window. Without JavaScript, on a touch screen, or with reduced motion requested, the section stays still and reads the same.

This is smoothscroll

paste.ui.smoothscroll glides the links in the bar, in the first section and in the list below to their section, then writes the address, so Back returns to where you were. Each of those lists is a SectionNav declared with smoothscroll = true; links outside one stay native.

  • Back to the top
Code for this section 
<nav class="paste-ui-section-nav site-links" data-paste-smoothscroll aria-label="Try it">
    <ul class="paste-ui-section-nav-items">
        <li class="paste-ui-section-nav-item">
            <a class="paste-ui-section-nav-link" href="#intro">Back to the top</a>
        </li>
    </ul>
</nav>
@paste.surface.components.html.sectionNav(SectionNav(
  items = Seq(NavItem("Back to the top", "intro")),
  sticky = false,
  cssClass = "site-links",
  ariaLabel = Some("Try it"),
  smoothscroll = true

This is the section nav

The bar of links under the first section is one SectionNav doing three jobs. paste.ui.stickynav marks it once that section has scrolled away, and the page's CSS pins the bar to the top. paste.ui.scrollspy underlines the section you are reading, with a mouse or trackpad; on a touch screen it stands down unless the nav opts in. Its links glide with smoothscroll. The logo is a Logo declared with scrollTop = true: paste.ui.scrolltop takes it back to the top without reloading the page or leaving a # in the address.

This is paste core

Paste started in 2011, to power high-performance webviews inside early iPhone apps. The libraries of the day imposed an application structure, as Backbone did, or offered a generic toolkit, as underscore did, and jQuery, Zepto, YUI 2, YUI 3 and Closure did some of both. Paste stayed next to the browser's own interfaces and added only what they lacked.

Browsers have since closed most of those gaps, so this page's markup, styles and events are the platform's own. What paste core still adds is a loader for classic scripts named by module: paste.define and paste.require start each module once everything it declared has arrived, from any static host, with no bundler or import map. With it come the few utilities the Elements share, such as dom, event, util and has.

The page loads no bundle. Its tag block marks each module as loading and requests each versioned file in turn.

This is paste-assetgraph

paste-assetgraph compiles the styles and the modules into files named by their content, such as heroscroll.<hash>.v1.min.css, and prints the tags each page carries. A static host serves them as they are; nothing runs on the server.

Code for this section 
<!-- paste-assetgraph css: site paste.ui.heroscroll -->
<link rel="stylesheet" href="/css/heroscroll.<hash>.v1.min.css"/>
<link rel="stylesheet" href="/css/site.<hash>.v1.min.css"/>
<!-- /paste-assetgraph -->
sh scripts/fetch-deps.sh            # the pinned releases, checked
sh scripts/build-dist.sh            # build dist/ and check every tag block
sh scripts/build-dist.sh --refresh  # rewrite stale tag blocks for review
